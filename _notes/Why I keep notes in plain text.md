Plain text outlives every app I've used. A Markdown file I wrote years ago still opens anywhere, while notes locked in an app tend to disappear with it.

So the rule is simple: write in files, publish from the same files.

## What this changes

- I stop thinking about *where* a note lives.
- Publishing is moving a file into a folder.
- Nothing needs exporting.

See also [[The Lighthouse Keeper]] — a story drafted the same way.
