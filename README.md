# Website

Jekyll site published from this Obsidian folder.

- `_notes/` — notes. Any `.md` file here is published at `/notes/<name>/`.
- `_stories/` — short stories. Published at `/stories/<name>/`.
- `about.md` — the About page.
- `_config.yml` — site title, description, Buttondown username.

Every published file needs a `date:` block at the top (use the "Website note" template).

Preview locally: `bundle exec jekyll serve` → http://localhost:4000
